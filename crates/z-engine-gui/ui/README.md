# Z Engine GUI frontend

Svelte 5 + Bits UI + Vite, hosted by Tauri 2.

Read **[`docs/design/gui-ui-guide.md`](../../../docs/design/gui-ui-guide.md)** before changing this tree. `AGENTS.md` at the repo root is the structure contract.

```
npm install
npm test
npm run check
npm run build
```

Tauri: from `crates/z-engine-gui`, `cargo tauri dev`.
