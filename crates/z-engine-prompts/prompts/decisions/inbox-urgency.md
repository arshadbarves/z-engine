A coding agent needs the user's attention or is telling them something. The input names the kind of item (an approval, a question, a plan to review, or a notice) and its text. How urgent is it for the user?

- low: It can wait; nothing stops or goes wrong if the user looks later.
- normal: The user should look soon, but nothing is at risk.
- high: The agent is stopped until the user answers, or something failed or is at risk.
