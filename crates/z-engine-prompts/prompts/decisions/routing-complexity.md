How much reasoning does this coding task need? The state holds the user's request; for a subagent it also names the agent type.

- simple: A small, well-defined change or a quick question: one file, an obvious fix, a lookup or an explanation.
- moderate: A normal change across a few files that needs some reading and a test run.
- complex: A large or unclear task: a design decision, a refactor across many files, a hard bug, or work with many steps.
